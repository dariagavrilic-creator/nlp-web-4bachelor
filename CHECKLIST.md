- [ ] Команда сформирована, роли распределены и записаны

- [ ] Заполнена карточка проекта
- [ ] Составлен обзор решений, не менее трёх позиций
- [ ] Заполнен реестр рисков, не менее пяти позиций

**Проверка выбора задачи**

- [ ] Двадцать примеров прогнаны через готовую модель
- [ ] Показано, что готовое решение справляется недостаточно хорошо
- [ ] Названо пороговое значение метрики, ниже которого подход считается неработающим

**Данные**

- [ ] Скрипт сбора в репозитории, данные — нет
- [ ] Собрано не менее 500 единиц
- [ ] Проведена нормализация, найдено не менее трёх видов дефектов
- [ ] Проведена дедупликация, доля дубликатов зафиксирована
- [ ] Прочитаны глазами десять случайных единиц
- [ ] Проверены правовые основания использования материала
- [ ] Собрана статистика: объём, распределение длин, баланс категорий

**Разметка**

- [ ] Определено, откуда берётся разметка
- [ ] Если разметка ручная — описаны правила и разобрано не менее трёх спорных случаев

**Разделение**

- [ ] Выборка разделена, пропорции зафиксированы
- [ ] Проверено отсутствие утечки: при группировке разделение по группам
- [ ] Тестовая часть отложена и в настройке не используется

**Контракт API**

- [ ] Формат запроса определён: поля, типы, обязательность
- [ ] Формат ответа определён
- [ ] Описано поведение при пустом вводе и слишком длинном тексте
- [ ] Указано ограничение на длину текста
- [ ] Контракт согласован с тем, кто ведёт веб-часть
- [ ] Заглушка написана и работает

**Публикация**

- [ ] Составлен dataset card

**На занятии:** демонстрация 6 минут, вопросы 3 минуты.

## Веха 2 — 17.11 (гр. 1) / 19.11 (гр. 2). Модель и передача

**Эксперименты**

- [ ] Базовое решение реализовано, результат зафиксирован
- [ ] Проверено не менее трёх подходов
- [ ] Каждый запуск занесён в журнал экспериментов
- [ ] Зафиксированы версии библиотек и начальные значения
- [ ] Все подходы сравниваются на одной тестовой части

**Оценка**

- [ ] Задача измерена не менее чем двумя метриками, расхождение объяснено
- [ ] Обоснован выбор основной метрики
- [ ] Построена матрица ошибок

**Анализ ошибок**

- [ ] Разобрано вручную не менее двадцати неверных предсказаний
- [ ] Построена типология, не менее трёх типов с примерами
- [ ] Для каждого типа сформулировано предположение о причине
- [ ] Указано, что восходит к модели, а что к данным или разметке
- [ ] Определено, на каких данных модель применять не следует

**Передача в веб-часть**

- [ ] Функция возвращает результат **ровно по контракту**
- [ ] Проверено поведение на пустом вводе
- [ ] Проверено поведение на очень длинном тексте
- [ ] Проверено поведение на тексте не на том языке
- [ ] Замерено время работы на одном тексте
- [ ] Все зависимости внесены в `requirements.txt`
- [ ] Веса модели доступны либо указано её имя на HuggingFace
- [ ] Контракт с вехи 1 не изменился, либо изменение согласовано и обосновано

**Роли**

- [ ] Смена ролей произведена, распределение записано

**На занятии:** демонстрация 6 минут, вопросы 4 минуты, запуск модели вживую.
