# Автоматическая обработка естественного языка · проект семестра

**Группы:** 3834504/30101 и 3834504/30102, 4 курс бакалавриата
**Команды:** 2–3 человека · **Пары:** 7 у группы 1, 8 у группы 2

---

## О дисциплине

Опыт работы с отдельными инструментами обработки языка к этому моменту приобретён. Предметом дисциплины является доведение работы до законченного вида: собранные и описанные данные, обоснованно измеренное качество, разобранные ошибки, воспроизводимый репозиторий.

Работа ведётся командами по полному проектному циклу — от постановки задачи до передачи результата.

**Результат семестра:** модель, решающая выбранную задачу, с описанным набором данных, метриками и анализом ошибок, в репозитории с воспроизводимым запуском.

---

## Связь с веб-программированием

Дисциплина ведётся параллельно с «Основами Web программирования». Результат этой дисциплины — функция; результат веб-программирования — сервис вокруг этой функции.

**Дисциплины оцениваются раздельно и независимо.** Работоспособность сайта не влияет на оценку по АОЕЯ, качество модели не влияет на оценку по вебу. Технически это обеспечивается контрактом API и заглушкой — см. [API_CONTRACT.md](API_CONTRACT.md).

| Эта дисциплина | Веб-программирование |
|---|---|
| Задача, данные, разметка | Проектирование API |
| Обучение и оценка модели | Серверная часть, интерфейс |
| Анализ ошибок, ограничения | Публикация, документация сайта |
| Репозиторий, dataset card, model card | Демонстрационная версия |
