# Банк тем

Темы для командного проекта, 2–3 человека, 7–8 пар.

**Общее требование ко всем темам:** задача выражается как функция «текст на входе → структура на выходе». Это условие связки с веб-программированием: то, что нельзя вызвать запросом, нельзя обернуть в сервис.

У каждой темы указано:
- **Вход → выход** — заготовка контракта API;
- **Данные** — где брать и почему они доступны;
- **Минимальная версия** — что должно работать к вехе 2 при любом развитии событий;
- **На сайте** — что показывает интерфейс, чтобы веб-часть имела содержание;
- **Сложность** — низкая / средняя / высокая.

# Трек А. Классификация текстов

Возвращает категорию и уверенность. Самый предсказуемый трек: доводится до конца практически всегда.

### А1. Определитель уровня сложности текста для изучающих русский

Оценивает, какому уровню владения языком соответствует текст, и объясняет, что именно делает его сложным.

**Вход → выход:** `{text}` → `{level: "B1", score, factors: {long_sentences, rare_words, syntax_depth}}`
**Данные:** учебные тексты с указанием уровня из открытых пособий и сайтов для изучающих РКИ; тексты новостных сайтов с адаптированными версиями.
**Минимальная версия:** три уровня, вердикт по вставленному тексту.
**На сайте:** текст с подсветкой сложных мест, шкала уровня, список редких слов.
**Сложность:** средняя.

### А2. Классификатор тональности отзывов узкой области

Тональность в конкретной предметной области — кафе, книги, онлайн-курсы, косметика. Смысл в узости: готовые модели на специальной лексике ошибаются.

**Вход → выход:** `{text}` → `{label, score, all_scores, keywords}`
**Данные:** отзывы с оценками в звёздах — разметка получается сама.
**Минимальная версия:** три класса, вердикт с уверенностью.
**На сайте:** ввод отзыва, вердикт, подсветка повлиявших слов.
**Сложность:** низкая.

### А3. Определитель типа текста

Различает новость, рекламу, инструкцию, художественный текст, научный, официально-деловой.

**Вход → выход:** `{text}` → `{type, score, all_scores, markers}`
**Данные:** тексты с разных типов сайтов, категория следует из источника.
**Минимальная версия:** четыре типа.
**На сайте:** вердикт плюс список формальных признаков, по которым он вынесен.
**Сложность:** низкая.

### А4. Стилометрический определитель авторства

По тексту предполагает автора из закрытого списка. Классическая филологическая задача количественными методами.

**Вход → выход:** `{text}` → `{author, score, all_scores, style_features}`
**Данные:** произведения 5–10 авторов из открытых библиотек, нарезанные на фрагменты.
**Минимальная версия:** пять авторов, фрагменты от 500 слов.
**На сайте:** вердикт, распределение вероятностей по авторам, стилевой профиль текста.
**Сложность:** средняя.

### А5. Определитель эпохи текста

Относит текст к периоду по языковым признакам: лексике, орфографии, синтаксису.

**Вход → выход:** `{text}` → `{period, score, dated_markers}`
**Данные:** тексты разных периодов из открытых библиотек и корпусов.
**Минимальная версия:** три периода.
**На сайте:** вердикт и подсветка датирующих признаков.
**Сложность:** средняя.

### А6. Маршрутизатор обращений абитуриентов

Относит вопрос абитуриента к нужному разделу: поступление, документы, общежитие, стоимость, программы.

**Вход → выход:** `{text}` → `{category, score, suggested_contact}`
**Данные:** вопросы из открытых групп и форумов; при нехватке — синтетические, порождённые языковой моделью и проверенные вручную.
**Минимальная версия:** пять категорий.
**На сайте:** ввод вопроса, категория, ссылка на нужный раздел сайта.
**Сложность:** низкая.

### А7. Детектор недобросовестной рекламы в объявлениях

Различает добросовестные и манипулятивные формулировки: скрытые условия, ложная срочность, размытые обещания.

**Вход → выход:** `{text}` → `{verdict, score, flags: [{type, fragment}]}`
**Данные:** объявления с досок, размеченные по формальным признакам.
**Минимальная версия:** три типа манипулятивных приёмов.
**На сайте:** текст с подсветкой найденных приёмов и объяснением каждого.
**Сложность:** средняя.
**Условие:** обязательный раздел об ограничениях — инструмент не выносит юридических оценок.

# Трек Б. Извлечение именованных сущностей

Возвращает список сущностей с границами в тексте. 

### Б1. Извлечение лингвистических терминов из научных статей

Находит термины предметной области, которых нет в готовых моделях.

**Вход → выход:** `{text}` → `{entities: [{text, type, start, end, definition}]}`
**Данные:** аннотации и статьи с CyberLeninka, eLibrary. Разметка частично автоматизируется по словарю терминов.
**Минимальная версия:** извлечение по словарю плюс модель на размеченной сотне абзацев.
**На сайте:** статья с подсвеченными терминами, всплывающие определения, выгрузка глоссария.
**Сложность:** средняя.

### Б2. Извлечение топонимов из художественных текстов

Находит географические названия и различает реальные и вымышленные.

**Вход → выход:** `{text}` → `{entities: [{text, type, start, end, coordinates}]}`
**Данные:** произведения из открытых библиотек; координаты из открытых географических баз.
**Минимальная версия:** извлечение топонимов без привязки к координатам.
**На сайте:** текст с подсветкой плюс карта с точками.
**Сложность:** средняя.

### Б3. Извлечение персонажей и их упоминаний

Находит персонажей, сводит разные именования одного лица (Раскольников, Родион, Родя) и считает встречаемость.

**Вход → выход:** `{text}` → `{characters: [{canonical_name, mentions: [{text, start, end}], count}]}`
**Данные:** художественные тексты из открытых библиотек.
**Минимальная версия:** извлечение имён без сведения вариантов.
**На сайте:** список персонажей с частотностью, граф совместной встречаемости.
**Сложность:** высокая — сведение вариантов имени сложнее, чем кажется.

### Б4. Извлечение требований из вакансий

Находит в тексте вакансии навыки, языки, опыт, условия.

**Вход → выход:** `{text}` → `{entities: [{text, type: "skill"|"language"|"experience", start, end}]}`
**Данные:** вакансии с открытых сайтов; разметка частично по словарю навыков.
**Минимальная версия:** три типа сущностей.
**На сайте:** вакансия с подсветкой, сводная таблица требований, сравнение нескольких вакансий.
**Сложность:** низкая.

### Б5. Извлечение дат и событий из дневников и мемуаров

Находит датировки, включая нечёткие («на третий день после Пасхи»), и события при них.

**Вход → выход:** `{text}` → `{events: [{date_text, date_normalized, event, start, end}]}`
**Данные:** дневники и мемуары из открытых архивов.
**Минимальная версия:** извлечение явных дат с нормализацией.
**На сайте:** временна́я шкала с событиями, переход к фрагменту текста.
**Сложность:** средняя.

### Б6. Извлечение состава и действий из рецептов

Находит ингредиенты, количества, действия, время.

**Вход → выход:** `{text}` → `{ingredients: [{name, amount, unit}], steps: [{action, duration}]}`
**Данные:** рецепты с кулинарных сайтов, структура частично размечена самим сайтом.
**Минимальная версия:** ингредиенты с количествами.
**На сайте:** рецепт с подсветкой, автоматический список покупок, пересчёт на число порций.
**Сложность:** низкая. Хороший выбор для команды, которой важно гарантированно доделать.

# Трек В. Семантический поиск

Возвращает ранжированный список фрагментов. Разметка почти не нужна — трек подходит командам, которые не хотят возиться с ручной разметкой.

### В1. Поиск по учебным материалам

Поиск по смыслу в конспектах, методичках, презентациях курса.

**Вход → выход:** `{query, top_k}` → `{results: [{id, text, score, source, page}]}`
**Данные:** материалы своих курсов, с разрешения преподавателей.
**Минимальная версия:** поиск по одному курсу.
**На сайте:** строка поиска, выдача с подсветкой, переход к источнику.
**Сложность:** низкая.

### В2. Подбор научной литературы по описанию темы

По описанию темы курсовой находит близкие публикации и группирует по подтемам.

**Вход → выход:** `{query, top_k}` → `{results: [{title, authors, year, abstract, score}], clusters}`
**Данные:** аннотации с CyberLeninka или через открытые API.
**Минимальная версия:** поиск без группировки.
**На сайте:** ввод темы, список публикаций, группировка по подтемам.
**Сложность:** средняя.

### В3. Поиск цитаты по смыслу

Находит в собрании произведений фрагмент по описанию: «где герой рассуждает о совести».

**Вход → выход:** `{query, top_k}` → `{results: [{text, score, work, chapter}]}`
**Данные:** произведения из открытых библиотек, нарезанные на фрагменты.
**Минимальная версия:** поиск по одному произведению.
**На сайте:** строка запроса, найденные фрагменты с контекстом.
**Сложность:** низкая.

### В4. Вопросно-ответная система по регламентам

Отвечает на вопросы о правилах — учебных, библиотечных, общежития — со ссылкой на пункт документа.

**Вход → выход:** `{query}` → `{answer, sources: [{document, section, text}], confidence}`
**Данные:** открытые регламенты и положения университета.
**Минимальная версия:** поиск релевантного пункта без порождения ответа.
**На сайте:** вопрос, ответ, обязательная ссылка на исходный пункт.
**Сложность:** средняя.
**Условие:** система обязана показывать источник ответа. Ответ без ссылки на документ не засчитывается.

### В5. Подбор похожих текстов в коллекции

Находит в собрании тексты, похожие на заданный: похожие вакансии, курсы, статьи, отзывы.

**Вход → выход:** `{text, top_k}` → `{results: [{id, text, score, why_similar}]}`
**Данные:** любая однородная коллекция от 500 текстов.
**Минимальная версия:** поиск похожих без объяснения сходства.
**На сайте:** ввод текста, лента похожих, объяснение сходства.
**Сложность:** низкая.

# Трек Г. Преобразование текста

Возвращает преобразованный текст. 

### Г1. Упрощение официально-делового текста

Переписывает канцелярит на понятный русский, показывая, что изменилось.

**Вход → выход:** `{text, mode}` → `{original, result, changes: [{from, to, reason}], readability_before, readability_after}`
**Данные:** объявления, инструкции, регламенты. Для оценки — метрики читабельности и оценка людьми.
**Минимальная версия:** упрощение с показом изменений на десяти текстах.
**На сайте:** два окна рядом, подсветка изменений, шкала читабельности до и после.
**Сложность:** средняя.

### Г2. Генератор упражнений по тексту

По загруженному тексту порождает задания: пропуски, вопросы на понимание, задания на лексику, с ключами.

**Вход → выход:** `{text, exercise_type, count}` → `{exercises: [{question, options, answer, explanation}]}`
**Данные:** любые тексты; оценка — экспертная, преподавателями.
**Минимальная версия:** один тип упражнений.
**На сайте:** загрузка текста, выбор типа, готовые упражнения, печать с ключами и без.
**Сложность:** средняя.

### Г3. Сокращение научных аннотаций

Сжимает аннотацию до одного-двух предложений, сохраняя главное.

**Вход → выход:** `{text, max_length}` → `{summary, compression_ratio, kept_terms}`
**Данные:** аннотации с CyberLeninka; для оценки — сравнение с заголовками и ключевыми словами.
**Минимальная версия:** экстрактивное сокращение — выбор важнейших предложений.
**На сайте:** исходный текст и сводка рядом, регулятор длины.
**Сложность:** средняя.

### Г4. Порождение заголовков

По тексту предлагает несколько вариантов заголовка разного характера: нейтральный, информативный, привлекающий внимание.

**Вход → выход:** `{text, style}` → `{headlines: [{text, style, score}]}`
**Данные:** новости с настоящими заголовками — готовая пара «текст → заголовок».
**Минимальная версия:** один вариант заголовка.
**На сайте:** текст, несколько вариантов на выбор, сравнение с настоящим заголовком.
**Сложность:** средняя.

### Г5. Нормализатор пользовательских текстов

Приводит небрежный текст в порядок: раскрывает сокращения, исправляет очевидные опечатки, восстанавливает пунктуацию и регистр.

**Вход → выход:** `{text}` → `{result, corrections: [{from, to, type, position}]}`
**Данные:** комментарии и посты; эталон получается искусственной «порчей» аккуратных текстов.
**Минимальная версия:** восстановление регистра и очевидных опечаток.
**На сайте:** два окна, подсветка исправлений, возможность отклонить каждое.
**Сложность:** средняя. Способ получения данных через порчу эталона — сильная сторона темы: разметка получается в любом объёме.

# Как выбрать тему

Тема принимается, если на все четыре вопроса ответ «да»:

1. Задача выражается как «текст на входе → структура на выходе»?
2. Данные можно получить **на этой неделе**?
3. Есть минимальная версия, которая работает, даже если остальное не успеется?
4. Готовые модели решают эту задачу недостаточно хорошо? (Проверьте до выбора: возьмите двадцать примеров и прогоните через готовую модель.)

Четвёртый вопрос отсеивает темы, которые не дают материала для работы. Если готовая модель справляется, задачу нужно сузить: взять более специальную предметную область, более тонкое различение категорий, менее типичный материал.

# Чего лучше не брать

**Задачи без проверяемого результата.** «Анализ образа героя», «исследование метафор» — интересно, но нет способа измерить качество и нечего оборачивать в сервис.

**Задачи, требующие разметки с нуля в большом объёме.** Следует брать то, где разметка уже есть.

**Задачи на материале, к которому нет доступа.** Медицинские записи, внутренние документы организаций, переписка.
