# Мой NLP-сервис

Учебный проект курса «Основы web-программирования», пары по теме "fastAPI".

## Что внутри

| Файл | Зачем |
|---|---|
| `main.py` | веб-часть: эндпоинты, проверка входных данных, коды ответов |
| `nlp.py` | анализ текста: функция `analyze(text, mode) -> dict`, про веб ничего не знает |
| `API.md` | контракт сервиса: что принимает, что отвечает |
| `test_api.py` | проверка: делает запросы к работающему серверу и печатает, что уже готово |
| `check_env.py` | проверка окружения |

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Сервер поднимется на http://127.0.0.1:8000. Документация и ручная проверка —
http://127.0.0.1:8000/docs. Остановить: Ctrl+C.

## Проверка

Пока сервер работает, в **другом** окне терминала:

```bash
python test_api.py
```

Скрипт напечатает список проверок с отметками. Незакрытые пункты — это ваши
следующие шаги.

Модуль анализа можно проверить и без сервера:

```bash
python nlp.py
```

## Пример запроса

```bash
curl -X POST http://127.0.0.1:8000/api/analyze ^
  -H "Content-Type: application/json" ^
  -d "{\"text\": \"Язык устроен так.\", \"mode\": \"stats\"}"
```

(В PowerShell перенос строки — знак `^`, в Linux и macOS — `\`.)

Или из Python:

```python
import requests
r = requests.post("http://127.0.0.1:8000/api/analyze",
                  json={"text": "Язык устроен так.", "mode": "stats"})
print(r.json())
```
